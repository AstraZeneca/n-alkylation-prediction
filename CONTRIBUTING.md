# Contributing

This repository accompanies a scientific publication (Selectivity Prediction for the Nitrogen Alkylation Reaction) and is released primarily as a record of
the code used to produce its results, at Maturity Level 0.

As such, this project is **not currently seeking active code
contributions** (new features, refactors, etc.). Its priority is
reproducibility of the published results rather than ongoing development.

## Reporting issues

Bug reports are welcome. If you find a problem — for example, a
discrepancy between the code and the methodology described in the paper,
or an error that prevents the code from running as documented in
`README.md` — please open an issue describing:

- what you ran (command / script) and what data it was run on,
- what you expected to happen,
- what actually happened (including the full error message, if any).

## Pull requests

If you would like to propose a fix, small pull requests addressing a
specific, described issue are welcome and will be reviewed by the
maintainer (see `AUTHORS.md`). Please open an issue first to discuss
larger changes before investing time in a pull request.
